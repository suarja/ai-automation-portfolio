# Prompts Claude pour Techniciens

Bienvenue dans cette collection de prompts adaptés aux techniciens et professionnels non-développeurs. Ces prompts vous aideront à tirer parti de Claude pour automatiser vos tâches quotidiennes, sans avoir besoin de connaissances en programmation.

## 📝 Prompt de Rédaction de Documentation

Pour créer de la documentation technique claire :

```
Je dois créer une documentation pour [sujet/produit/processus].

**Public cible :** [débutants / intermédiaires / experts]

**Objectif de la documentation :**
[Expliquer comment utiliser / Résoudre des problèmes / Former des utilisateurs]

**Points à couvrir :**
1. [Point 1]
2. [Point 2]
3. [Point 3]

**Format souhaité :**
- Guide pas à pas
- FAQ
- Vidéo script
- [Autre]

Crée une documentation complète, structurée et facile à comprendre. Utilise des exemples concrets et des captures d'écran imaginaires (décris ce qu'elles devraient montrer).
```

## 🎓 Prompt de Création de Formation

Pour concevoir des modules de formation :

```
Je veux créer une formation sur [sujet].

**Durée cible :** [X heures]
**Niveau :** [Débutant / Intermédiaire / Avancé]
**Format :** [Présentiel / En ligne / Hybride]

**Objectifs pédagogiques :**
À la fin de cette formation, les participants seront capables de :
1. [Objectif 1]
2. [Objectif 2]
3. [Objectif 3]

**Contraintes :**
- Budget : [limité / moyen / élevé]
- Matériel disponible : [liste]
- Profil des apprenants : [description]

Propose :
1. Un plan de formation détaillé
2. Des exercices pratiques
3. Des supports pédagogiques
4. Des critères d'évaluation
5. Un timing précis par module
```

## 📊 Prompt d'Analyse de Données Simples

Pour analyser des données sans Excel complexe :

```
J'ai les données suivantes à analyser :

[Coller vos données ici - tableau, liste, etc.]

**Questions :**
1. [Quelle tendance observe-t-on ?]
2. [Quelles sont les valeurs aberrantes ?]
3. [Quelles recommandations pour améliorer ?]

**Format de réponse souhaité :**
- Résumé visuel (décris des graphiques pertinents)
- Insights clés (3-5 points principaux)
- Recommandations actionnables
- Prochaines étapes

Utilise un langage simple et évite le jargon statistique.
```

## 💬 Prompt de Communication Client

Pour rédiger des emails professionnels :

```
Je dois écrire un email à [type de destinataire] concernant [sujet].

**Contexte :**
[Décrivez la situation]

**Objectif de l'email :**
[Informer / Demander / Résoudre un problème / Annoncer une décision]

**Ton souhaité :**
[Formel / Amical / Neutre]

**Points clés à inclure :**
1. [Point 1]
2. [Point 2]
3. [Point 3]

**Contraintes :**
- Longueur : [Court / Moyen / Détaillé]
- Deadline mentionnée : [Oui/Non]
- Pièces jointes : [Liste]

Rédige un email professionnel, structuré et engageant.
```

## 🔍 Prompt de Recherche et Synthèse

Pour synthétiser des informations complexes :

```
Je dois faire une synthèse sur [sujet].

**Sources d'information :**
[Lister les sources ou coller des extraits]

**Questions clés à répondre :**
1. [Question 1]
2. [Question 2]
3. [Question 3]

**Format de sortie :**
- Résumé exécutif (1 paragraphe)
- Points clés (bullets)
- Détails par section
- Recommandations

**Public cible :**
[Managers / Équipe technique / Clients / Direction]

Crée une synthèse claire et actionnable. Mets en évidence les informations critiques et les décisions à prendre.
```

## 🛠️ Prompt de Résolution de Problèmes Techniques

Pour diagnostiquer et résoudre des problèmes :

```
Je rencontre un problème avec [équipement/logiciel/système].

**Description du problème :**
[Décrivez ce qui ne fonctionne pas]

**Quand est-ce arrivé :**
[Depuis quand ? Après quel événement ?]

**Ce que j'ai déjà essayé :**
1. [Action 1]
2. [Action 2]

**Impact :**
[Critique / Important / Mineur]

**Informations système :**
- Version : [X]
- Configuration : [Y]
- Environnement : [Z]

Propose un diagnostic étape par étape et des solutions classées par probabilité de succès. Commence par les solutions les plus simples.
```

## 📋 Prompt de Création de Procédure

Pour documenter un processus :

```
Je veux créer une procédure pour [processus/tâche].

**Fréquence d'exécution :**
[Quotidien / Hebdomadaire / Mensuel / Ponctuel]

**Personnes concernées :**
[Qui exécute / Qui valide / Qui est informé]

**Étapes actuelles (si connues) :**
1. [Étape 1]
2. [Étape 2]
...

**Contraintes :**
- Temps alloué : [X minutes/heures]
- Outils disponibles : [Liste]
- Niveau d'expertise requis : [Débutant / Intermédiaire / Expert]

Crée une procédure détaillée avec :
1. Objectif de la procédure
2. Prérequis
3. Étapes numérotées avec actions claires
4. Points de contrôle
5. Que faire en cas de problème
6. Critères de réussite
```

## 📱 Prompt de Communication Interne

Pour créer des communications d'équipe :

```
Je veux communiquer [information] à mon équipe.

**Type de communication :**
[Annonce / Mise à jour / Changement / Célébration / Alerte]

**Informations clés :**
[Décrire l'information à communiquer]

**Public :**
- Taille de l'équipe : [X personnes]
- Niveau de détail attendu : [Élevé / Moyen / Faible]
- Familiarité avec le sujet : [Experts / Novices / Mixte]

**Canal de communication :**
[Email / Slack / Teams / Réunion / Newsletter]

**Ton :**
[Motivant / Informatif / Urgent / Célébration]

Rédige une communication claire, engageante et adaptée au canal choisi. Inclus un call-to-action si nécessaire.
```

## 💡 Conseils d'Utilisation

### Maximisez l'Efficacité de Claude :

1. **Soyez spécifique** : Plus vous donnez de contexte, meilleurs sont les résultats
2. **Itérez** : Demandez des ajustements si le premier résultat n'est pas parfait
3. **Sauvegardez** : Gardez vos meilleurs prompts pour les réutiliser
4. **Personnalisez** : Adaptez ces templates à votre contexte spécifique

### Structure Gagnante :

Chaque prompt devrait contenir :
- **Contexte** : Où, quand, pourquoi
- **Objectif** : Ce que vous voulez accomplir
- **Contraintes** : Limites et exigences
- **Format** : Comment vous voulez le résultat
